# WhatsApp Scraper

A Python-based WhatsApp Scraper project designed to automate the collection and extraction of publicly accessible WhatsApp-related information using web scraping and automation techniques.

## Features

- Automated scraping workflow
- Browser automation
- Structured data extraction
- Organized data handling
- Efficient scraping process
- Easy-to-configure project structure

## Technologies Used

- Python
- Selenium
- BeautifulSoup
- Requests
- WebDriver
- Git & GitHub

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sorforaj99tech/whatsapp_scraper.git
   ```

2. Navigate to the project directory:

   ```bash
   cd whatsapp_scraper
   ```

3. Create a virtual environment:

   ```bash
   python -m venv env
   ```

4. Activate the virtual environment:

   ```bash
   env\Scripts\activate
   ```

5. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the main application using:

```bash
python main.py
```

Adjust the command according to the project's actual entry-point file.
